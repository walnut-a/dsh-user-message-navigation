# User Message Minimap（用户消息导航轨）插件 PRD

> 对外名称：DSH User Message Minimap｜中文名称：用户消息导航轨｜目标产品：DeepSeek Harness Web｜状态：原型验证｜优先级：P1

## 目标

在长 Session 的 Chat 视图左侧显示一条用户消息导航轨（Minimap）。每条已加载、已持久化的用户消息对应一个标记，用户可以识别当前轮次并快速跳转到历史指令。插件卸载后不得留下数据、监听器或布局依赖。

## V1 范围

- 默认至少 4 条用户消息时显示。
- 标记顺序与 Chat 中的用户消息顺序一致。
- 滚动时反馈当前用户轮次。
- 支持点击、键盘和指针拖动跳转。
- 提供用户消息文本预览；空文本使用回退文案。
- 窄空间、空白会话和非 Chat 视图不显示。
- 尊重“减少动效”设置。
- 仅覆盖当前已加载历史窗口，不假装已经索引完整 Session。

## 非目标

- 不索引 Assistant、Tool、Command 或系统事件。
- 不调用模型生成标题或摘要。
- 不修改 Session 日志、模型请求或持久化格式。
- 不提供跨 Session 搜索、书签或分享链接。

## 插件边界

正式实现应由 DSH 提供稳定的可叠加导航插槽、用户消息投影和按消息定位接口。原型允许通过现有 Chat DOM 属性验证交互价值，但这些属性必须集中在兼容层内，并明确标记为非稳定依赖。

## 验收

- 0–3 条用户消息时不显示，第 4 条出现后显示。
- 点击或键盘触发后目标消息进入视口且不会被 Composer 遮挡。
- 滚动 Chat 时当前标记随阅读位置更新。
- 拖动导航轨可连续浏览，松手不额外跳转。
- 辅助功能树包含“用户消息”导航区、逐项跳转名称及当前项。
- 启用减少动效后不执行平滑滚动和高亮动画。
- 安装、重启和卸载后 DSH 均可正常启动，卸载后无残留 UI。

## 发布前验证

- 纯函数单元测试：预览、阈值和拖动索引。
- 组件测试：注册/处置、键盘、指针、当前项和辅助功能。
- 真实 DSH Web：长对话、分页、窄宽度、浅色/深色主题。
- `pnpm pack` 后从 tarball 安装，验证构建产物完整。
